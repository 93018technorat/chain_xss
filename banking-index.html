banking.postbank.de — cross-origin postMessage → navigate → javascript: XSS

The banking SPA trusts any message whose origin shares the registrable domain (removeSubdomain = split('.').slice(-2) → both www.postbank.de and banking.postbank.de collapse to postbank.de). A navigate message is passed to unsafeExternalRedirect(target) → location.href = target with no scheme allowlist, and CSP script-src 'unsafe-inline' lets javascript: run.

A page on a non-postbank.de origin (like this one) can't send the message directly, so this PoC first bootstraps onto the postbank.de origin through the confirmed www.postbank.de reflected XSS (YellowMap zoomLevel → self['eval'](window['name'])), then opens banking and fires the navigate message.

  1. Click Run PoC (the click lets the browser open the windows).
  2. A www.postbank.de tab opens (bootstrap) which opens the banking /demo/ window.
  3. In the banking demo window, click Weiter (demo login — a real logged-in victim skips this).
  4. alert("PBX banking.postbank.de") fires on the banking.postbank.de origin.
